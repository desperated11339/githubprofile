# How to publish the profile

GitHub shows a profile README only when it lives in a public repository whose name is **exactly** your username.

Example: if your username is `kristian`, the repository must be named `kristian`.

This folder (`.githubprofile`) is the working copy. You do not upload it under that name.

## Upload

1. Create the public repository `YOUR_USERNAME/YOUR_USERNAME`.
2. Upload these files to the **root** of that repository, not inside a subfolder:
   - `README.md`
   - `banner.svg`
3. Leave `PUBLICAR.md` out if you do not want it in the repository. The profile only renders `README.md`.

The banner is an SVG. It stays sharp on desktop and mobile because it scales with `width="100%"`. The accent blue is `#3794ff`, the same blue used in the Vuxy portfolio.
